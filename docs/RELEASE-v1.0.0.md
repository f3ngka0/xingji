# 行迹 v1.0.0

首次发布包含 Android 客户端、Node.js + SQLite 服务端、Web 分享地图和 Docker 部署配置。

## 本版内容

- 软件与项目统一命名为「行迹」，应用图标沿用首屏位置标记。
- 黑白灰界面、高级设置、行程历史与共享地图。
- 首页右上角 **⋮ → 服务器地址**：填写 IP、端口或域名，验证后保存；首次使用也可从首页直接配置。
- 支持可信内网 HTTP，公网要求 HTTPS。配置持久保存；有本地行程时阻止切换服务器，避免发送旧凭证与旧轨迹。
- 目的地选填；真实位置先写入 Room，再上传；分享链接仅提供只读访问。
- 可选服务端地名解析，支持附近地点与相对方向、距离。
- 签名 Release APK、源码 ZIP 和 SHA-256 下载校验值。

## 使用与限制

下载并安装 `xingji-v1.0.0.apk`，部署服务端与 Web，然后在客户端设置服务器地址。具体步骤见 [README](../README.md) 与 [发布说明](RELEASING.md)。

- APK 不包含实际高德 Key。默认使用 Android 系统定位与 OpenStreetMap；高德搜索、定位与地名解析按文档自行配置。
- 模拟器注入坐标用于检验定位数据链路，不能证明真机 GPS、锁屏、Doze 或手机厂商省电策略下的可靠性，仍需真机验证。
- 此环境未安装 Docker，已提供部署文件，但没有在此环境执行 Docker 部署。
- GitHub 仓库为私有仓库；分享软件与部署源码需具有仓库访问权限。
- 签名私钥保存在仓库外。请备份并保留相同证书以发布后续覆盖更新。
