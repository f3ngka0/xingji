# 行迹 v1.1.0

一键位置共享重构：首页定位状态 + 一次点击开始行程，按行程记录地图提供方，设置全部收入设置页。应用更名为「行迹」。服务端含向后兼容数据库迁移（迁移 004），旧数据自动按 OSM 显示。

## 本版内容

- 首页显示真实定位状态与地名（「定位已就绪 · 合浦县 · 廉州镇附近」式，来自系统 Geocoder 或高德定位；无法解析时显示「当前位置已获取」，不伪造地名），支持点击在地图上查看当前位置与失败后重新定位。
- 一次点击「开始共享」直接创建行程：捕获首个有效定位 → 服务端建行程 → 写入首点 → 启动前台服务 → 进入共享中页。彻底移除出发地表单；行程起点即第一个有效实测位置，标题自动为「从某地出发」。
- 每段行程创建时记录 `mapProvider`（OSM / AMAP），Android 内嵌地图与家人打开的 Web 页面按行程自身提供方渲染；修改设置不影响历史行程。存储保持 WGS-84，展示层统一坐标适配器只做一次转换，杜绝重复偏移。
- 设置中心：服务器 / 地图服务 / 记录模式 / 更新间隔 / 最长共享时间 / 权限状态 / 关于，均为 Bottom Sheet 交互；默认值只影响以后新行程。地图服务支持基础模式（OpenStreetMap，零配置）与增强模式（高德：地点名称、POI 搜索与目的地），高德 Key 存入设备加密存储，两个 Key 齐全才启用增强模式。
- 增强模式下可在共享中页右上角 ⋮ 添加、修改或清除目的地（不影响位置记录）；基础模式不出现任何目的地或 POI 入口。
- 共享中页极简重排：状态行、标题、地图、当前位置地名与可靠时速；同步信息仅在异常时显示。已结束详情含完整轨迹、最后更新与到达地点，撤销/删除收进 ⋮。
- 管理接口新增目的地端点与 `latestPositionLabel`；服务端可选逆地名为最新位置解析「地名 + 方位 + 距离」。
- OSM 瓦片源切换为大陆网络可达的社区镜像（`tile.openstreetmap.de`，仍为 OSM 数据）；AMAP 行程在部署未配置高德 JS 底图时自动回退开源地图并轻提示。
- 签名 Release APK、源码 ZIP 和 SHA-256 下载校验值。

## 升级说明

- 直接覆盖安装（与 v1.0.0 同签名、同包名）。首次进入新版会自动完成本地数据库升级，原行程与轨迹保留。
- 服务端需更新到本版以支持 `mapProvider` 与目的地端点；旧服务端搭配新 App 时行程仍可创建（字段被忽略），但地图提供方与目的地功能不可用。
- 若要在 Web 端渲染高德底图，部署侧需另配 `AMAP_JS_KEY`、`AMAP_JS_SECURITY_CODE` 与 `AMAP_SECURITY_PROXY_ENABLED=true`；未配置时自动回退开源地图。
